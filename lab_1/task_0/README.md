### Task 0 — Image Uploader (Taipy)

#### Завдання

Ознайомитися з фреймворком **Taipy** та створити простий вебінтерфейс для завантаження і відображення зображення.

#### Опис роботи

Програма створює вебінтерфейс за допомогою **Taipy GUI**.
Користувач може:

1. Завантажити зображення.
2. Натиснути кнопку «Показати зображення».
3. Отримати повідомлення про успішне завантаження.
4. Переглянути завантажене зображення.

#### Основні елементи програми

**Функція `show_image(state)**`

* Функція отримує об'єкт стану `state`, який містить завантажене зображення `state.input_image`.
* Якщо зображення не завантажене, користувач отримує повідомлення:
`«Будь ласка, завантажте зображення.»` (змінній `state.message` присвоюється відповідний текст, а `state.output_image` очищається).
* Якщо зображення завантажене, програма повертає повідомлення:
`«Зображення успішно завантажено!»` та передає об'єкт зображення у `state.output_image`.

**Інтерфейс Taipy**
Для створення інтерфейсу використано **Markdown-розмітку** зі спеціальними контролами Taipy:

* `page` — рядок з Markdown-структурою, що виступає контейнером інтерфейсу;
* `# Task 0 - Image Uploader` — заголовок сторінки;
* `<|{input_image}|file_selector|>` — елемент для вибору та завантаження файлу зображення (з підтримкою Drag & Drop);
* `<|Показати зображення|button|>` — кнопка для запуску обробки;
* `<|{message}|input|>` — поле для відображення системного повідомлення;
* `<|{output_image}|image|>` — віджет для відображення завантаженого зображення.

**Обробка натискання кнопки**
Після натискання кнопки викликається функція `show_image()` через атрибут `on_action`:

```python
<|Показати зображення|button|on_action=show_image|>

```

Передача даних між елементами UI та кодом відбувається автоматично завдяки механізму **Two-Way Data Binding** через об'єкт `state`.
