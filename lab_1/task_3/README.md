# Task 3 — Система розпізнавання образів з навчанням (Taipy)

## Опис проекту
У цій лабораторній роботі реалізовано систему розпізнавання образів із можливістю попереднього навчання з вчителем на навчальній послідовності графічних зразків для 3 класів.

---

## Основні можливості
1. **Навчання з вчителем:** Завантаження серії зразків для кожного з 3 класів.
2. **Статистичний аналіз кластерів:**
   * **Метод геометричних центрів:** Обчислення математичного сподівання (усередненого вектора) $M[X]$ для кожної компоненти кластера.
   * **Метод ортогональних областей:** Визначення діапазонів $[X_{\min}, X_{\max}]$ для кожної компоненти в просторі ознак.
3. **Гнучка класифікація невідомого образу:**
   * Підтримка двох алгоритмів рішення:
     1. **За геометричними центрами:** Знаходження мінімальної Евклідової відстані до математичного сподівання кластера.
     2. **За ортогональними областями:** Перевірка входження вектора ознак у гіперпаралелепіпед допуску класу.

---

## Алгоритми та методи

### 1. Геометричні центри
Для класу $C_j$ з $N$ навчальними зразками геометричний центр обчислюється як:
$$\bar{x}_k^{(j)} = \frac{1}{N} \sum_{i=1}^{N} x_{k, i}^{(j)}$$
Класифікація здійснюється вибором класу з найменшою Евклідовою відстанню:
$$d(X_{\text{unk}}, \bar{X}^{(j)}) = \sqrt{\sum_{k=1}^{25} (x_k^{\text{unk}} - \bar{x}_k^{(j)})^2}$$

### 2. Ортогональні області
Для кожного класу визначаються межі $k$-ї компоненти:
$$x_{k, \min}^{(j)} = \min_{i} x_{k,i}^{(j)}, \quad x_{k, \max}^{(j)} = \max_{i} x_{k,i}^{(j)}$$
Образ належить до класу $C_j$, якщо:
$$\forall k \in [1, 25]: x_{k, \min}^{(j)} \le x_k^{\text{unk}} \le x_{k, \max}^{(j)}$$
