# Task 1 — Побудова вектора ознак (Taipy)

## Опис проекту
У цій лабораторній роботі розроблено веб-додаток для побудови абсолютного та нормованого векторів ознак графічного зображення з використанням фреймворку **Taipy**. Програма призначена для первинного аналізу та підготовки даних у задачах розпізнавання образів (цифр, літер, логотипів).

---

## Основні функції
Користувач може:
1. Завантажити чорно-біле зображення у форматі **BMP**.
2. Натиснути кнопку **«Побудувати вектор ознак»**.
3. Переглянути завантажене зображення з накладеною червоною сіткою **5×5**.
4. Отримати **абсолютний вектор ознак** (кількість інформативних пікселів у кожному блоці).
5. Отримати **нормований вектор ознак** (відносні значення).

---

## Алгоритм роботи (функція `process_image`)

1. **Попередня обробка:**
   * Зображення переводиться у відтінки сірого (`L` mode).
   * Автоматично розраховуються розміри областей для поділу сіткою $5 \times 5$ (25 прямокутних областей).

2. **Обчислення абсолютного вектора:**
   * У кожній області підраховується кількість пікселів зображення (чорний колір, значення інтенсивності $< 128$):
     ```python
     black_pixels = np.sum(cell < 128)
     ```
   * Отримані значення формують абсолютний вектор:
     $$X = (x_1, x_2, \dots, x_{25})$$

3. **Нормування вектора:**
   * Нормування виконується шляхом ділення значення кожної компоненти на загальну суму чорних пікселів $\sum x_i$:
     $$x_i' = \frac{x_i}{\sum x_i}$$
   * Якщо чорні пікселі відсутні, створюється нульовий вектор відповідної довжини.

4. **Візуалізація:**
   * За допомогою `PIL.ImageDraw` поверх оригінального зображення наноситься червона сітка $5 \times 5$.
   * Оброблений малюнок зберігається та виводиться на веб-сторінку.

## Інтерфейс (Taipy GUI)

Інтерфейс побудований за допомогою Markdown-синтаксису Taipy:

* **Файловий селектор (`file_selector`):** Забезпечує завантаження `.bmp` файлів.
* **Кнопка (`button`):** Запускає обробку зображення через прив'язану функцію `on_action=process_image`.
* **Компонент зображення (`image`):** Відображає результат поділу на сітку $5 \times 5$.
* **Багаторядкові текстові поля (`input` з `multiline=True`):** Використовуються для виводу масивів абсолютного та нормованого векторів.
* **Розмітка сторінки (`<|layout|>`):** Розділяє вихідні дані та результати на зручні колонки.
